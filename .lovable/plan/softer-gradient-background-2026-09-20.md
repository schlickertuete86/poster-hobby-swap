# Softer Gradient Background

## Goal
Replace the current sharply marbled backdrop with a soft-focus, atmospheric gradient inspired by the uploaded artworks, while leaving the successful listings interface unchanged.

## Changes
- Create a new full-page background artwork using the existing coral, periwinkle, near-black, and pale cream palette.
- Use broad diffused color blooms, gentle tonal transitions, subtle glow, and analog grain rather than visible brush strokes, veins, hard edges, lines, or borders.
- Keep the composition irregular and editorial, with enough dark and light variation for the black foreground typography to remain readable.
- Replace only the current background image and tune its display treatment for a seamless result across mobile and desktop.
- Preserve all cards, typography, controls, spacing, and interactions exactly as they are.

## Verification
- Review the updated screen at mobile and desktop sizes.
- Confirm the backdrop has no distinct contour lines or harsh boundaries, the gradient remains visible behind the page, and all foreground content retains strong contrast.
