# Navigation klarer gliedern

## Umsetzung
- Die drei Navigationspunkte durch feine vertikale Linien sichtbar voneinander trennen.
- Den horizontalen Abstand um die Trennlinien vergrößern, damit jeder Punkt als eigener Link erkennbar ist.
- Auf kleinen Bildschirmen kompaktere Abstände beibehalten, ohne die horizontale Navigation umzubrechen.
- Aktiven und fokussierten Link weiterhin über die bestehende Unterstreichung kennzeichnen.

## Prüfung
- Darstellung auf Desktop und Mobil prüfen.
- Sicherstellen, dass lange Linktexte nicht überlappen und die Navigation scrollbar bleibt.
